# Private source map example

Keep this file outside the public repository after customizing it.

| Source | What it contains | When it may be searched |
|---|---|---|
| `PATH_TO_THOUGHTS.md` | personal posts and raw ideas | user asks to find a topic |
| `PATH_TO_NOTES/` | experiences and learning records | a selected topic needs evidence |
| `PATH_TO_CONTENT_TASKS/` | prior task folders | deduplication or continuation |

Rules:

- Use only paths the user explicitly authorizes.
- Search before ingesting; do not merge files into a knowledge base by default.
- Save only source citations or short excerpts necessary for the current task.
